# Changelog

All notable changes to this project are documented here. The format is based on
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to
[Semantic Versioning](https://semver.org/spec/v2.0.0.html). Entries are generated by
release-plz from conventional commits.

## [Unreleased]

## [0.3.0](https://github.com/cosmtrek/t3bot/compare/v0.2.0...v0.3.0) - 2026-11-10

### Added

- treat settled threads as handled and close their tasks

## [0.2.0](https://github.com/cosmtrek/t3bot/compare/v0.1.0...v0.2.0) - 2026-11-06

### Added

- Local builds report `X.Y.Z-dev+<commit>`; release builds report the plain version
- `t3bot doctor` shows the running version and whether a newer release exists

### Other

- Releases are cut with release-plz: a release PR per change set, merged to release

## [0.1.0](https://github.com/cosmtrek/t3bot/releases/tag/v0.1.0) - 2026-11-06

### Added

- Initial public release: follow-up ledger (`add`, `ls`, `edit`, `open`, `close`, `report`,
  `pending`, `annotate`, `tick`), `@t3bot` skill, systemd timers.
- Prebuilt static Linux binaries (x86_64, aarch64), `install.sh`, `t3bot upgrade`.
- `t3bot init`, `t3bot config`, `t3bot doctor`.
